ЧТО ЭТО И ЗАЧЕМ
==============
Файлы из этой папки — обновление проекта Students-Journal (журнал студентов ЧелГУ),
которое нужно скопировать на прод-сервер (Windows Server, C:\Journal\Journal\Students-Journal).
Если путь на сервере другой — подставьте свой.

Что нового в этом обновлении:
  Автозаполнение журнала из расписания. На странице журнала появилась кнопка
  «Заполнить»: выбираете период (сегодня / завтра / на дату / эта неделя /
  следующая неделя / две недели / месяц / с даты по дате) — и занятия создаются
  автоматически из расписания сайта ТФ ЧелГУ: только ваши пары в выбранной группе,
  тема = дисциплина, предмет создаётся сам (если его ещё нет), посещаемость —
  всем «Присутствует». Повторное заполнение не создаёт дубликаты.

  Сопоставление с расписанием подбирается автоматически (преподаватель по ФИО,
  группа по названию). При несовпадении названий (например, журнал «ТФИ-101» —
  это расписание «Т1-ИТб-11») нужная группа выбирается вручную ОДИН раз
  и запоминается навсегда (по id, переименования на сайте расписания не страшны).

ВАЖНОЕ ОГРАНИЧЕНИЕ: кнопка полностью заработает только после того, как на сайте
расписания (http://tfcsu.ru:8100, тот же сервер) будет установлен пакет
«для копирования 12» (API /api/teachers/ и /api/teacher_schedule/).
Пока его нет, при заполнении появится ошибка связи — это ожидаемо.
Адрес API берётся из переменной SCHEDULE_API_URL (по умолчанию
http://127.0.0.1:8100 — для прода подходит, в .env на сервере менять НЕ нужно).


ШАГ 1. СКОПИРОВАТЬ ФАЙЛЫ
=======================
Скопируйте содержимое ЭТОЙ папки поверх папки проекта на сервере
(C:\Journal\Journal\Students-Journal), сохранив структуру:

  prisma\schema.prisma                  -> C:\Journal\Journal\Students-Journal\prisma\schema.prisma
  src\lib\schedule-api.ts               -> C:\Journal\Journal\Students-Journal\src\lib\schedule-api.ts
  src\app\actions\schedule.ts           -> C:\Journal\Journal\Students-Journal\src\app\actions\schedule.ts
  src\app\(protected)\journal\page.tsx  -> C:\Journal\Journal\Students-Journal\src\app\(protected)\journal\page.tsx
  .env.example                          -> C:\Journal\Journal\Students-Journal\.env.example

ВАЖНО: файл .env на сервере НЕ трогайте — его в этой папке нет, и он должен
остаться со своими паролями. Менять в нём ничего не нужно.

Новые зависимости НЕ появились — pnpm install на сервере запускать не нужно.
Схема базы меняется (два новых поля: сопоставления с расписанием) — вручную
применять ничего не нужно: обёртка при следующем запуске сама выполнит
prisma db push, как обычно.


ШАГ 2. ПЕРЕЗАПУСК
================
Перезапустите приложение, как при обычном обновлении:

  schtasks /End /Task StudentsJournal
  schtasks /Run /Task StudentsJournal

(или вручную: pnpm prod в папке проекта).

Первый запуск пересоберёт проект (код менялся, отпечаток сборки не совпадёт)
и применит схему БД, затем стартует как обычно.
